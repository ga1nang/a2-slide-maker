# Köln slide deck (German A2 exam)

A funny, consistent HTML/CSS/JS slide deck for a 3-person German A2 presentation about Cologne,
generated with Claude Code. No build step: open `index.html`, press `F` for fullscreen.

- `PROMPT.md` - the single prompt that produces this (use it in plan mode)
- `index.html`, `style.css`, `slides.js`, `fonts/` - the deck (works offline)
- `export_pdf.py`, `export_pptx.py` - export to PDF / PPTX (headless Chrome)
- `sprechen.md` - one speaker's script (speaker names anonymised)
- `figures/` - photos are not included, see `figures/README.md`
- `CLAUDE.md` - architecture notes and gotchas for Claude Code

Slides of speakers A and C are placeholders; speaker B's slides are the worked example.
